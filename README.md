# Do Inferno ao Céu

Jogo de plataforma vertical: salte entre plataformas e suba do Inferno ao Céu, atravessando três mundos. Se cair, a jornada termina.

## Controles

- Mover: setas esquerda/direita ou A e D.
- Pular: Espaço, W ou seta para cima.
- No celular: use os botões na tela.
- Clique em Jogar para começar ou reiniciar.

Os sprites foram gerados por inteligência artificial (IA).

Abra index.html no navegador para jogar localmente.
